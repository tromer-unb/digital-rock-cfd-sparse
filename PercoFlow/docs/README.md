# Documentation

Suggested reading order for a new user: the main [README](../README.md), then the tutorial
[examples/README.md](../examples/README.md), then the pages below as needed.

| page | read it to … |
|---|---|
| [THEORY.md](THEORY.md) | understand the equations, the permeability definition and why each modelling choice was made |
| [INPUTS_OUTPUTS.md](INPUTS_OUTPUTS.md) | prepare an image or a mesh, choose options, and read every file of a run directory |
| [OPENFOAM.md](OPENFOAM.md) | install OpenFOAM and interpret the independent finite-volume cross-check |
| [BENCHMARKS.md](BENCHMARKS.md) | see how PercoFlow is verified and validated, with criteria and the results of this release |
| [REPRODUCIBILITY.md](REPRODUCIBILITY.md) | reproduce the reference numbers exactly, on another machine |
| [AUDIT_AND_TRACEABILITY.md](AUDIT_AND_TRACEABILITY.md) | audit a result, check the repository integrity, release a new version |
| [GLOSSARY.md](GLOSSARY.md) | look up a term (χ_c, A50, probe line, Taylor–Hood, …) |
| [reference_results/](reference_results/README.md) | inspect the benchmark report and the example results produced with this release |

For developers: [../src/percoflow/README.md](../src/percoflow/README.md) maps every module, function and equation, and
[../tests/README.md](../tests/README.md) explains what each test protects.
